#### 1.1 重构 `_prepare_features`（G1, G5 + 修复分箱BUG）

**文件**: `app/services/ml_service.py`

**改动**:
- 移除年保费分箱代码（第 78-83 行的 `Annual_Premium_bin` 逻辑）
- 修复 Gender 编码：`Male=0, Female=1`（与文档一致，当前是 Male=1 反了）
- `_prepare_features` 拆分为两步：`_encode_features(df)` 只做类别编码，返回编码后的 DataFrame；标准化由 `StandardScaler` 在训练时 fit、预测时 transform
- 返回 `(X_encoded, y)` 其中 X_encoded 是编码后但未标准化的特征矩阵

```python
def _encode_features(df: pd.DataFrame):
    """类别编码（不标准化，标准化由 scaler 在训练/预测时处理）"""
    df = df.copy()
    df["gender"] = df["gender"].map({"Male": 0, "Female": 1}).fillna(0).astype(int)
    df["vehicle_age"] = df["vehicle_age"].map({"< 1 Year": 0, "1-2 Year": 1, "> 2 Years": 2}).fillna(0).astype(int)
    df["vehicle_damage"] = df["vehicle_damage"].map({"Yes": 1, "No": 0}).fillna(0).astype(int)
    for col in FEATURE_COLS:
        if col in df.columns:
            df[col] = df[col].fillna(0)
    X = df[FEATURE_COLS].values
    y = df["response"].values if "response" in df.columns else None
    return X, y
```

**文件**: `app/services/llm_service.py`

```python
import re, json

_client = None

def _get_client():
    global _client
    if _client is None and is_llm_configured():
        from openai import OpenAI
        _client = OpenAI(api_key=settings.LLM_API_KEY, base_url=settings.LLM_API_BASE)
    return _client

def generate_email_content(customer: dict, prompt_template: str) -> dict:
    profile = _build_customer_profile(customer)
    filled = prompt_template.format(**profile)

    if not is_llm_configured():
        return {"subject": "", "content": filled, "status": "failed"}

    try:
        client = _get_client()
        resp = client.chat.completions.create(
            model=settings.LLM_MODEL,
            messages=[{"role": "user", "content": filled}],
            temperature=0.7,
        )
        text = resp.choices[0].message.content.strip()
        text = re.sub(r'^```json\s*', '', text)
        text = re.sub(r'\s*```$', '', text)
        parsed = json.loads(text)
        return {"subject": parsed.get("subject", ""), "content": parsed.get("content", ""), "status": "generated"}
    except Exception:
        return {"subject": "", "content": filled, "status": "failed"}
```

#### 4.1 修复高潜筛选 threshold 计算（G11）

**文件**: `app/services/email_service.py`（从 email.py 移入）

```python
import numpy as np
from app.models.customers import Customer

def get_targets(db, percentile, page, per_page):
    all_customers = db.query(Customer).filter(Customer.predicted_prob.isnot(None)).all()
    if not all_customers:
        raise BizException(3002, "无预测数据，请先进行预测", 400)
    all_probs = [c.predicted_prob for c in all_customers]
    threshold = float(np.quantile(all_probs, percentile))
    # 筛选 >= threshold 的客户
    targets = sorted(all_customers, key=lambda c: c.predicted_prob, reverse=True)
    targets = [c for c in targets if c.predicted_prob >= threshold]
    # 分页
    total = len(targets)
    start = (page - 1) * per_page
    page_items = targets[start:start + per_page]
    return {
        "threshold": threshold,
        "total": total,
        "customers": [...],
    }
```

#### 4.2 批量导入改用 bulk_insert_mappings 分批 commit（G12）

**文件**: `app/models/customers.py`

```python
@classmethod
def bulk_create(cls, db: Session, rows: list[dict], user_id: int) -> int:
    db.query(cls).delete()
    db.commit()
    batch_size = 5000
    for row in rows:
        row["uploaded_by"] = user_id
    for i in range(0, len(rows), batch_size):
        batch = rows[i:i + batch_size]
        db.bulk_insert_mappings(cls, batch)
        db.commit()
    return len(rows)
```

## 假设与决策

| 决策点 | 选择 | 原因 |
|--------|------|------|
| 年保费分箱 | 删除，改为 StandardScaler | 文档明确要求 StandardScaler；分箱代码有 BUG |
| Gender 编码 | Male=0, Female=1 | 文档 2.3 明确规定 |
| load_model 向后兼容 | 检测旧格式裸 model | 避免导入旧模型文件崩溃 |
| model_visualizer | 优先读 params，fallback 重新计算 | 兼顾新旧数据 |
| LLM client | 模块级单例 | 避免每次调用新建 client |
| 反编码 | 用映射表转自然语言 | 文档 4.1 要求，Customer 存原始值但需转中文描述 |
| 测试范围 | ML/LLM/email/data 核心服务层 | 关键路径覆盖，不追求全覆盖 |
