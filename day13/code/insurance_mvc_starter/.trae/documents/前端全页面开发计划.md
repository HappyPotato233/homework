## 步骤四：各页面功能详述

### 4.1 认证页面（auth.js）

**路由**：`#/login`、`#/register`

| 页面 | 功能 |
|------|------|
| 登录 | 用户名+密码表单，调 POST /auth/login，成功存 token 跳转 dashboard |
| 注册 | 用户名+密码表单（密码≥6位），调 POST /auth/register，成功自动登录 |

设计：居中卡片，Deep Teal 渐变背景，左侧品牌区域 + 右侧表单（桌面端），移动端单列

### 4.2 Dashboard（app.js 内嵌）

**路由**：`#/dashboard`

| 区块 | 数据来源 |
|------|----------|
| 精准营销漏斗指标条 | GET /data/statistics + GET /model/best + GET /email/targets |
| 数据概览卡片 | GET /data/statistics（total/gender_dist/response_dist/age_stats） |
| 最佳模型卡片 | GET /model/best（model_name/roc_auc） |
| 快捷操作 | 按钮链接到上传数据/训练模型/生成邮件 |

### 4.3 数据管理（data.js）

**路由**：`#/data`

| 子页面 | 接口 | 功能 |
|--------|------|------|
| 数据上传 | POST /data/upload | 拖拽/选择 Excel，显示上传进度 + 质量报告结果 |
| 客户列表 | GET /data/customers | 分页表格 + 筛选器（gender/age/insured/keyword），显示 predicted_prob gauge |
| 数据统计 | GET /data/statistics | 统计卡片 + 分布图 |
| 质量报告 | GET /data/quality | 缺失值/重复/类型表格 |
| EDA 可视化 | GET /data/visualization/{chart_type} | 4 种图表 tab 切换，base64 PNG 渲染 |

### 4.4 模型管理（model.js）

**路由**：`#/model`

| 子页面 | 接口 | 功能 |
|--------|------|------|
| 训练模型 | POST /model/train | admin 专属，选择算法/参数，训练结果展示各模型指标对比 |
| 实验记录 | GET /model/experiments | 分页表格，显示指标 + is_best 标记 |
| 全量预测 | POST /model/predict | 确认按钮 + 预测结果计数 |
| 上传预测 | POST /model/predict_upload | 上传 Excel 预测，显示统计 + 预测结果列表 |
| 评估可视化 | GET /model/visualization/{chart_type} | 4 种图表（ROC/指标对比/混淆矩阵/特征重要性），confusion_matrix 和 feature_importance 需选模型 |
| 导出模型 | GET /model/export/{model_name} | admin 专属，下载 .joblib |
| 导入模型 | POST /model/import | admin 专属，上传 .joblib |

### 4.5 邮件管理（email.js）

**路由**：`#/email`

| 子页面 | 接口 | 功能 |
|--------|------|------|
| 高潜客户 | GET /email/targets | 分位数滑块 + 分页表格，概率 gauge 可视化 |
| 生成邮件 | POST /email/generate | 选择客户/自动取 top N，生成结果列表（成功/失败状态） |

| 邮件记录 | GET /email/records | 分页表格，admin 附 created_by_username，状态筛选 |
| 邮件详情 | GET /email/records/{id} | 完整 HTML 正文预览 |
| 编辑邮件 | PUT /email/records/{id} | 编辑主题/正文 |
| 标记状态 | PATCH /email/records/{id} | 标记 sent/failed |
| 删除/批量删除 | DELETE /email/records/{id} / DELETE /email/records | 确认弹窗 + 批量选择 |

### 4.6 操作日志（log.js）

**路由**：`#/logs`（仅 admin 可见）

## 步骤五：技术实现方案

### 5.1 SPA 路由（app.js）
- Hash 路由：`window.location.hash` 变化触发 `hashchange` 事件
- 路由表：`{ "#/login": renderLogin, "#/dashboard": renderDashboard, ... }`
- 路由守卫：未登录 → 跳 `#/login`；user 角色访问 admin 路由 → 跳 `#/dashboard`
- 页面渲染：每个路由函数返回 HTML 字符串，插入 `#app` 容器

### 5.2 API 客户端（api.js）
- `api.request(method, path, options)` - 通用 fetch 封装
- 自动注入 `Authorization: Bearer <token>` header
- 统一响应处理：`code === 0` 返回 `data`，非 0 抛异常
- 401 处理：清除 token，跳转登录页
- `api.upload(path, file, fieldName)` - 文件上传封装
- `api.download(path)` - 文件下载封装（blob）

### 5.3 状态管理
- `App.state = { user: null, token: null }` - 内存状态
- `localStorage` 持久化 token
- `App.updateUser()` - 调 GET /auth/me 刷新用户信息
- 侧边栏根据 `user.role` 显示/隐藏 admin 菜单项

### 5.4 组件模式
- `App.card(title, content)` - 卡片组件
- `App.table(headers, rows)` - 表格组件
- `App.pagination(total, page, per_page, onPage)` - 分页组件
- `App.gauge(prob)` - 概率 gauge 条组件
- `App.badge(status)` - 状态徽章组件
- `App.modal(title, body)` - 模态框组件
- `App.toast(message, type)` - 提示通知组件
- `App.loading()` - 加载动画
